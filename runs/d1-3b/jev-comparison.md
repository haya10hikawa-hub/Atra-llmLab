## 3. 主要な失敗原因（d1）
1. **UPDATE を CREATE にする → Full Replay で同じ仕事が重複**（s85 のみの誤り最多：正解 UPDATE→予測 CREATE 9件）。Jev との差の主因。
2. **MERGE と UPDATE の混同**（状態変化の識別力 AUC 0.86。Jev も MERGE は 0.37 で、合成正解のあいまいさも疑われる＝UNKNOWN）。
3. **状態 UNKNOWN を DONE と断定**（正解 UNKNOWN の状態正解率：d1 0.36〜0.39、Jev preview 0.61）。余計な必須の原因。
- seed 差（交差検証の Formation）：定数学習率 0.109（mix-personal seed0/1）、cosine 0.029（psched0/1）。2 seed のみで確定ではない。
- プロンプト内で候補を信号より先に書くと s85 の誤マージ 1→14（Atra の書式は固定のため直ちに本番影響はない）。
- d1 の低確信度 20% を Jev に回すと Formation の誤りが 14.6→7.3件/100 **（既存出力からの推定。Full Replay では未実証）**。
