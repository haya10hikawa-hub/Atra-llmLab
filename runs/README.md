## 記録規約

- 事前：仮説、元のBaseline、反証可能な予測、データの分割、費用・品質の成功条件を明示する。
- 事後：実測、無効Run、変化量、棄却理由、未検証事項を残す。
- 原本のファイル構造やモデルAdapterを勝手に移動しない。実コード移管時は別Commitとする。
- 生成Goldと人間Gold、単発判断とFull Replay、開発データと封印データを常に区別する。
